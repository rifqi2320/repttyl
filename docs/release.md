# Release Flow

Repttyl releases are GitHub tag driven. A release tag builds the remote agent binaries and CLI package, then publishes them to a GitHub Release.

## Versioning

Use semantic versions:

```text
v0.1.0
v0.1.1
v0.2.0
```

Keep these versions aligned before tagging:

- root `package.json`
- `apps/cli/package.json`
- `packages/*/package.json`
- `agent/internal/version/version.go`

The Go module itself does not need a version field.

## Preflight

Run these locally before tagging:

```bash
pnpm install --frozen-lockfile
pnpm release:preflight
```

## First GitHub Setup

Create an empty GitHub repository, then wire this local repo to it:

```bash
git remote add origin git@github.com:repttyl/repttyl.git
git branch -M main
git push -u origin main
```

If the repo lives under a personal account first, use that remote URL instead and rename it later if needed.

## Release

Create and push a tag:

```bash
git tag -a v0.1.0 -m "v0.1.0"
git push origin v0.1.0
```

The `.github/workflows/release.yml` workflow publishes the GitHub Release.

## macOS Desktop Signing

macOS desktop DMGs must be signed and notarized. Without that, Gatekeeper may report that `Repttyl` is damaged when a user opens the downloaded app.

Configure these GitHub Actions secrets before publishing macOS desktop artifacts:

- `MACOS_CERTIFICATE_BASE64`: base64-encoded `.p12` Developer ID Application certificate
- `MACOS_CERTIFICATE_PASSWORD`: password for the `.p12` certificate
- `MACOS_SIGNING_IDENTITY`: optional explicit signing identity, for example `Developer ID Application: Example (TEAMID)`
- `APPLE_ID`: Apple ID for notarization
- `APPLE_ID_PASSWORD`: app-specific password for that Apple ID
- `APPLE_TEAM_ID`: Apple Developer Team ID

Create the base64 certificate value with:

```bash
base64 -i developer-id-application.p12 | pbcopy
```

## Artifacts

The release workflow uploads:

- `repttyl-<version>-linux-amd64.tar.gz`
- `repttyl-<version>-linux-arm64.tar.gz`
- `repttyl-<version>-darwin-amd64.tar.gz`
- `repttyl-<version>-darwin-arm64.tar.gz`
- `repttyl-<version>-windows-amd64.tar.gz`
- `repttyl-client-<version>.tar.gz`
- `repttyl-desktop-darwin-arm64-<version>.dmg`
- `repttyl-desktop-darwin-x64-<version>.dmg`
- `repttyl-desktop-linux-x64-<version>.tar.gz`
- `repttyl-desktop-win32-x64-<version>.zip`
- SHA256 files for agent archives
- SHA256 file for the CLI archive
- SHA256 files for desktop archives

## Notes

- The remote agent is the first artifact users need for SSH hosts.
- The CLI package is platform-independent but requires Node.js.
- Release notes are generated by GitHub from merged commits and PRs.
- Do not push local build output, `.nx`, `node_modules`, or `agent/bin`.
